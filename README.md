# Презентации ТЕХНОНИКОЛЬ

Свод правил и библиотека макетов слайдов в фирменном стиле TN Life (ТЕХНОНИКОЛЬ).
Собирает презентацию ИИ-ассистент: читает правила, выбирает макеты под содержание
и пишет сборку. Результат — `.pptx` 16:9, где текст, таблицы и диаграммы остаются
редактируемыми в PowerPoint.

## Как пользоваться

Дай ассистенту доступ к репозиторию и напиши:

> Собери презентацию по правилам из этого репозитория, начни с `START_HERE.md`.
> Вот бриф: …

Дальше он сам задаст недостающие вопросы и отдаст `.pptx` вместе со скриптом сборки.
К брифу можно приложить черновик презентации, таблицы с цифрами и скриншоты —
всё это пойдёт в дело. Картинок может не быть: на их месте появятся плейсхолдеры
с точным размером, а список недостающих изображений ассистент вернёт отдельно.

## Что внутри

| Путь | Что это |
|---|---|
| [`START_HERE.md`](START_HERE.md) | точка входа для ассистента: весь процесс от брифа до файла |
| [`rules/`](rules/) | сетка и координаты, бренд, язык, чек-лист приёмки |
| [`templates/`](templates/) | 17 макетов: когда применять, поля, готовый код |

| [`examples/tn-life-strategy/`](examples/tn-life-strategy/) | рабочая дека на 18 слайдов и её превью |

## Требования

Node.js 18+ и два пакета:

```bash
npm install
```

`pptxgenjs` собирает файл, `sharp` перекрашивает иконки из спрайта и логотип для
тёмного фона. Без `sharp` соберётся всё остальное.

Шрифт — [Inter](https://fonts.google.com/specimen/Inter), бесплатный. В `.pptx`
прописывается его имя, поэтому у тех, кто открывает презентацию, он должен быть
установлен. Если поставить его некому — собирайте с `Arial`, см. `rules/brand.md`.

Для проверки вёрстки нужны LibreOffice (`soffice`) и `pdftoppm` из Poppler.

## Собрать пример

```bash
npm install
node examples/tn-life-strategy/build.js
```

## Источник

ТЕХНОНИКОЛЬ. Первоисточник UI-кита: `@life_uikit/uikit`.
Если дизайн-система обновилась, обновляйте `assets/tokens/` и `rules/brand.md` вместе.
