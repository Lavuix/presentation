# Тема `digital` — TN Digital

Материалы TN Digital: гильдии и сообщества, митапы, техрадар, разборы
инструментов, внутренние отчёты цифрового блока. Аудитория — инженеры,
аналитики, продакты.

Источник — дека «Гильдия аналитиков TN Digital». Тёмный фон, градиент
фиолетовый → голубой → мятный, Mulish, моноширинные надзаголовки.

```js
const p = TN.newDeck({ title: 'Гильдия аналитиков', theme: 'digital' });
await TN.prepare();      // обязательно: свечение обложки и градиентная полоса
```

## Оформление

| Что | Значение |
|---|---|
| Фон контента | `#16171a`, подложка карточки `#1b1c20` |
| Основной текст | `#fafaf8`, вторичный `#a8aab1`, колонтитул `#8a8d94` |
| Линии | `#2c2d33` |
| Акцент | `#cc66ff` |
| Градиент | `#cc66ff` → `#00aeff` → `#8effba` |
| Шрифт | Mulish |
| Моноширинный | JetBrains Mono — надзаголовки, колонтитул, нумерация, подписи контактов |
| Обложка | тёмная, три пятна свечения справа, знак-шестиугольник, градиентная полоса |
| Полоса по краю | 6 px внизу каждого слайда |

Градиентной заливки в PPTX нет, поэтому свечение, полоса и знак собираются
в PNG через `sharp` и ставятся картинкой. Без `sharp` дека соберётся, но
обложка будет ровно-тёмной, а полоса — сплошной фиолетовой.

## Акценты

Три — это цвета фирменного градиента:

| Ключ | Цвет |
|---|---|
| `purple` | `#cc66ff` |
| `blue` | `#00aeff` |
| `mint` | `#8effba` |

Больше не выдумывать. Если элементов в ряду четыре, четвёртый снова
фиолетовый — это нормально, `TN.accent(i)` закольцовывает список сам.

Все три акцента светлые, поэтому текст на заливке акцентом — **тёмный**
(`C.onAccent` = `#16171a`). Белым по `#cc66ff` — 2,3 : 1, читать нельзя.

Экран целиком акцентом не заливается: разделитель, тезис и финал с `tone: 'red'`
берут `C.accentFill` = `#2b1440` — глубокий фиолетовый, надзаголовок на нём
акцентный. Полный `#cc66ff` во весь кадр слепит зал.

Зелёного и красного в палитре нет, а динамику показывать надо: `tone: 'green'`
даёт мятный `#8effba`, `tone: 'red'` — розово-красный `#ff6b81`.

## Шрифты у получателей

Mulish и JetBrains Mono — свободные, ставятся с Google Fonts. В `.pptx`
прописываются по имени: у кого их нет, тот увидит подстановку. Если дека
уходит наружу и шрифты ставить некому — переключись на брендовую тему,
а не подменяй шрифт в этой.

## Кегли

Крупные — свои: титул 112, разделитель 96, заголовок слайда 66, тезис 58,
надзаголовок 24. Основной текст (28), подписи (24) и заголовки карточек (36)
брендовые: под них выверена геометрия карточек.
