# Темы

Тема — это оформление деки: значения токенов, шрифт и обложка. Макеты, сетка
и координаты у всех тем общие, поэтому одна и та же дека собирается в любой теме
без правок вёрстки.

Тем четыре. Выбор темы — первое решение перед сборкой, до плана слайдов.

| Тема | Ключ | Когда брать | Обложка | Фон контента |
|---|---|---|---|---|
| [Брендовая](brand.md) | `brand` | дека от лица компании: стратегия, внешняя аудитория, годовые итоги | красная с кругом | белый |
| [Подразделение](division.md) | `division` | дека конкретного департамента или завода | чистый цветной экран | белый |
| [TN Digital](digital.md) | `digital` | материалы TN Digital: гильдии, митапы, техрадар, разбор инструментов | тёмная со свечением и знаком | почти чёрный |
| [TN Life Dark](dark.md) | `dark` | продуктовые презентации и демо TN Life | тёмная со свечением | почти чёрный |

Не уверен — бери `brand`. Тёмные темы хороши на проекторе в затемнённом зале
и в записи экрана; на печати и в светлой переговорной они проигрывают.

## Как включить

```js
const TN = require('./templates/_prelude');
const p = TN.newDeck({ title: 'Название деки', theme: 'digital' });
await TN.prepare();      // фоновая графика темы: свечение, градиентная полоса, знак
```

`prepare()` нужен темам с фоновой графикой (`digital`, `dark`). Забудешь —
дека соберётся, но градиентная полоса внизу слайдов станет сплошной линией.

Тему можно переключить и отдельно — `TN.useTheme('dark')`, — но только до
первого слайда: уже собранные слайды не перекрашиваются.

## Посмотреть темы

```bash
node examples/themes/build.js            # все темы
node examples/themes/build.js digital    # одна
```

Рядом со скриптом появятся `tn-brand.pptx`, `tn-division.pptx`,
`tn-digital.pptx`, `tn-dark.pptx`. В каждой деке — **все 28 макетов** на своих
слайдах: титул, разделители, агенда, метрики, features, cards, таблица,
диаграмма, process, timeline, compare, bullets, split, image, quote, statement,
финал. Открой и выбери.

Образцы собираются прямо из `templates/*.md`, поэтому не расходятся с шаблонами.
Файлы `.pptx` в git не хранятся (`.gitignore`) — их пересобирают командой выше.

## Что задаёт тема

| Задаёт | Не задаёт |
|---|---|
| цвета всех токенов | сетку, поля, координаты |
| шрифт и моноширинный шрифт | набор макетов |
| крупные кегли (титул, разделитель, заголовок, тезис) | кегли основного текста |
| обложку титула и финала | правила выбора макета |
| набор акцентов и их порядок | язык и тон текста |
| фоновую графику: свечение, полосу, знак | |

Кегли основного текста (`body`, `small`, `h3`, `h4`) у всех тем одинаковые:
под них выверена геометрия карточек, и увеличение ломает вёрстку.

## Ролевые токены

Имя токена — это **роль**, а не цвет. `C.bg` — фон слайда, каким бы он ни был;
`C.ink` — основной текст. В тёмной теме `bg` тёмный, а `ink` светлый.

| Токен | Роль |
|---|---|
| `bg` | фон контентного слайда |
| `surface` / `surfaceAlt` | подложка карточки / чётная строка таблицы |
| `line` / `lineStrong` | разделительная линия / рамка плейсхолдера |
| `ink` / `muted` / `soft` / `faint` | основной текст / вторичный / колонтитул / третьестепенное |
| `accent` / `accentDeep` / `accentTint` | акцент №1 / его затемнение / его подложка |
| `onAccent` / `onAccentDim` / `onAccentEye` | текст на заливке акцентом (карточка, кружок, полоса) |
| `accentFill` | заливка акцентного тона во весь экран: разделитель, тезис, финал |
| `onAccentFill` / `…Dim` / `…Eye` | текст на такой заливке |
| `deep` / `deepSoft` | тёмная заливка: шапка таблицы, тёмный разделитель / тёмная метрика |
| `onDeep` / `onDeepDim` | текст на тёмной заливке: основной / вторичный |
| `chip` | плитка под иконкой на тёмной заливке |
| `frame` | корпус устройства в макете `image` |
| `onCover*` | текст на обложке |

Отдельно от акцентов тема задаёт семантику: `TN.accent(0, 'green')` — улучшение,
`TN.accent(0, 'red')` — ухудшение. В брендовой теме это зелёный и красный из
палитры, в тёмных — свои цвета той же светлоты. Так `tone: 'green'` в таблице
означает «стало лучше» в любой теме, а не случайный цвет.

**Мелкая заливка и заливка во весь экран — разные роли.** Карточка или кружок
шага заливаются `accent` (ярко, это акцент), а разделитель на весь экран —
`accentFill`: в тёмной теме целый экран чистого акцента слепит зал.

Старые имена (`C.n100`, `C.red60`, `C.n15`, …) остались и тоже меняются вместе
с темой — они описаны в `rules/brand.md`. В новых сниппетах пиши ролевые:
`C.n100` в тёмной теме означает светлый текст, и это сбивает с толку.

**Чего не делать:** брать цвет напрямую (`'#e11b11'`) вместо токена. В брендовой
теме разницы не видно, а в тёмной такой слайд останется с красным пятном.

## Своя тема

Тема — объект в `templates/_themes.js`. Проще всего скопировать ближайшую
и поправить значения:

```js
const MY = Object.assign({}, BRAND, {
  bg: '#ffffff', ink: '#101418', accent: '#0b6b3a',
  accentDeep: '#064727', accentTint: '#e3f3ea',
  // … остальные роли
});

const THEMES = {
  // …
  green: {
    key: 'green', name: 'Зелёная', dark: false,
    font: 'Inter', mono: null,
    colors: MY, accents: MY_ACCENTS, type: BRAND_TYPE,
    logo: 'logo-black-rus.png',
    cover: { kind: 'accent', pattern: 'none' },
    bar: null,
  },
};
```

Поля темы:

| Поле | Значение |
|---|---|
| `colors` | все токены; проще взять `Object.assign({}, BRAND, { … })` |
| `accents` | акценты по порядку, `{ key, solid, tint, deep }`; три или шесть |
| `type` | шкала кеглей; меняй только крупные |
| `font` / `mono` | шрифт деки и моноширинный для надзаголовков (`null` — нет) |
| `cover.kind` | `accent` — заливка акцентом, `ink` — тёмный фон со свечением |
| `cover.pattern` | `circle` — декоративный круг, `none` — чистый экран |
| `semantic` | `{ green, red }` — цвета «лучше / хуже» |
| `cover.glow` | пятна свечения `{ x, y, r, color, alpha }`, доли от размера слайда |
| `cover.mark` | `true` или размер в px — знак-шестиугольник на обложке |
| `bar` | полоса по нижнему краю: `{ h, stops: ['#…', '#…'] }` или `null` |

После правок обязательно прогони проверку:

```bash
node themes/contrast.js          # контраст всех пар «текст на фоне»
node examples/themes/build.js    # собрать образцы и посмотреть глазами
```

Текст должен давать не меньше 4,5 : 1, крупный (от 48 px) — 3 : 1. Новая тема
обязана пройти без единого `FAIL`.
