# Тема `brand` — брендовая ТЕХНОНИКОЛЬ

Тема по умолчанию. Дека от лица компании: стратегия, годовые итоги, внешняя
аудитория, документы для руководства. Если заказчик не сказал иного — это она.

Полное описание палитры, типографики, иконок и логотипов — `rules/brand.md`.
Здесь только то, что отличает тему от остальных.

```js
const p = TN.newDeck({ title: 'Название деки', theme: 'brand' });
```

## Оформление

| Что | Значение |
|---|---|
| Фон контента | белый `#ffffff`, второй фон `#f3f5f7` |
| Основной текст | `#1e2228` |
| Акцент | фирменный красный `#e11b11` |
| Шрифт | Inter |
| Обложка | красная во всю плашку, декоративный круг `#ae1603` справа сверху |
| Полоса по краю | нет |

## Акценты

Шесть, всегда в этом порядке: красный, синий, зелёный, оранжевый, фиолетовый,
жёлтый. Первый — основной. Когда чередовать, а когда нет — `rules/brand.md`.

## Известные отклонения по контрасту

`node themes/contrast.js` помечает несколько пар брендовой палитры как «дев.» —
они не дотягивают до 4,5 : 1:

| Пара | Контраст |
|---|---|
| колонтитул `#8890a7` на белом | 3,18 |
| нумерация `#abb0c1` на белом | 2,16 |
| вторичный текст на подложке карточки | 4,40 |
| подпись на тёмной метрике | 2,99 |
| лид и мета на красной обложке | 4,00 и 3,65 |

Это значения корпоративной дизайн-системы, а не ошибка сборки. Менять их
в репозитории нельзя. Если дека идёт на большой экран в светлом зале — не ставь
в колонтитул и подписи ничего, что обязательно прочитать.
