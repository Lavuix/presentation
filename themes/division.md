# Тема `division` — подразделение

Дека конкретного департамента, завода или направления: внутренние итоги,
защита бюджета, представление команды. Аудитория своя, компания-в-целом
в кадре не нужна.

От брендовой отличается **только обложкой**: палитра, шрифт, макеты и
колонтитул те же. Отдельного фирстиля у подразделений нет, и выдумывать его
не нужно — достаточно другой обложки.

```js
const p = TN.newDeck({ title: 'Итоги года', theme: 'division' });
```

## Обложка

Чистый цветной экран без декоративного круга. Название подразделения — в поле
`left`, как и в брендовой теме.

```js
await title(p, {
  eyebrow: 'Итоги года · 2026',
  title: 'Логистика: −18 % к стоимости доставки',
  lead: 'Что сделали за год и что просим на следующий.',
  left: 'Департамент логистики',
  right: 'Декабрь 2026',
});
```

## Цвет обложки

По умолчанию — фирменный красный. Если у подразделения закреплён свой цвет
из палитры акцентов, передай его в `accentColor`:

```js
await title(p, { title: 'Итоги года', accentColor: C.blue60, left: 'ИТ-департамент' });
```

Брать разрешено **только** акценты из `rules/brand.md`:

| Подразделение | Токен |
|---|---|
| по умолчанию | `C.red60` |
| — | `C.blue60` |
| — | `C.green50` |
| — | `C.orange45` |
| — | `C.purple60` |
| — | `C.yellow50` |

Закрепление цветов за конкретными подразделениями — решение владельца бренда,
в репозитории его нет. Свой цвет мимо палитры не изобретать.

`accentColor` красит только обложку. Акцент внутри деки остаётся красным:
иначе чередование акцентов в карточках и на диаграммах перестанет читаться.

## Финал

Финальный слайд по умолчанию светлый. Чтобы он повторил обложку, передай
`tone: 'red'` — заливка возьмёт тот же акцент.
