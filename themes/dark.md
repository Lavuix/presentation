# Тема `dark` — TN Life Dark

Продуктовые презентации TN Life: демо, релизы, разбор метрик продукта,
показ интерфейса. Хорошо смотрится там, где на слайдах много скриншотов
тёмного интерфейса.

Источник — лендинг «TN Life — экосистема ТЕХНОНИКОЛЬ». Почти чёрный фон,
коралловый акцент, Inter.

```js
const p = TN.newDeck({ title: 'TN Life 2.0', theme: 'dark' });
await TN.prepare();      // обязательно: свечение обложки и полоса
```

## Оформление

| Что | Значение |
|---|---|
| Фон контента | `#08080a`, подложка карточки `#111113` |
| Основной текст | `#f4f4f5`, вторичный `#969698`, колонтитул `#808082` |
| Линии | `#1c1c1e` |
| Акцент | коралловый `#ff4e5b` |
| Градиент | `#ff4e5b` → `#ff8a66` |
| Шрифт | Inter |
| Обложка | тёмная, три пятна свечения справа, градиентная полоса |
| Полоса по краю | 4 px внизу каждого слайда |

Полупрозрачные токены лендинга (`rgba(255,255,255,0.08)` и подобные) сведены
к сплошным цветам поверх фона `#08080a`: в PPTX прозрачных слоёв интерфейса нет.

## Акценты

Три, из палитры лендинга:

| Ключ | Цвет |
|---|---|
| `coral` | `#ff4e5b` |
| `amber` | `#ff8a66` |
| `pink` | `#ff3c78` |

## Текст на акценте

На лендинге кнопки — белым по коралловому. На слайде так нельзя: белый по
`#ff4e5b` даёт 3,2 : 1, а заголовок карточки набирается 36 px — это не «крупный
текст» по WCAG. Поэтому `C.onAccent` здесь тёмный (`#14060a`), контраст 6,2 : 1.

Если нужна именно кнопка «как на лендинге» — это картинка интерфейса, а не
текст слайда, и она вставляется скриншотом.

Экран целиком коралловым тоже не заливается: разделитель, тезис и финал
с `tone: 'red'` берут `C.accentFill` = `#1f0709`, а коралловым на нём идёт
только надзаголовок.

Динамика: `tone: 'green'` — мятный `#5ef2a0`, `tone: 'red'` — коралловый `#ff4e5b`.

## Когда не брать

- Дека пойдёт на печать или в раздатку — тёмный фон съедает тонер и выглядит грязно.
- Половина слайдов — фотографии со светлым фоном: они будут «дырами» в тёмной деке.
- Внешняя аудитория, которая ждёт корпоративный красный, — тогда `brand`.
