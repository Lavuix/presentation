# Пример: стратегия продукта TN Life

Дека на 18 слайдов, по одному на каждый макет из `templates/`. Содержание вымышленное —
смысл примера в том, чтобы показать все макеты в работе и дать рабочий скелет сборки.

```bash
npm install
node examples/tn-life-strategy/build.js
```

Файл соберётся рядом: `tn-life-strategy.pptx` (в git не попадает).

Отрендеренные слайды — в `preview/`. Их же показывают шаблоны в `templates/*.md`.

## Что здесь смотреть

`build.js` устроен так, как надо собирать любую деку:

1. подключается пролог `templates/_prelude.js`;
2. каждый макет — функция, вставленная из `templates/*.md` без изменений;
3. `main()` вызывает их по порядку и подставляет контент;
4. счётчик `no` и константа `TOTAL` дают сквозную нумерацию — считаются только
   слайды с колонтитулом, то есть без титула, разделителей, тезиса, `split` и финала.

Скопируй `build.js`, оставь нужные функции, замени содержимое `main()`.
