# Сетка и координаты

## Холст

Слайд — **1920 × 1080 px**, соотношение 16:9. В PowerPoint это 13,333 × 7,5 дюйма.
Все шаблоны написаны в пикселях макета; пролог переводит их сам:

```js
const px = (n) => n / 144;   // px → дюймы: 144 px = 1 дюйм
const pt = (n) => n / 2;     // px → пункты кегля: 2 px = 1 pt
```

Значит, 68 px заголовка на слайде — это 34 pt в PowerPoint. Думай и пиши в пикселях,
конвертацию не делай руками.

## Поля

| Величина | px | Что это |
|---|---|---|
| `MX` | 88 | левое и правое поле |
| `MT` | 72 | верхнее поле |
| `MB` | 72 | нижнее поле |
| `CW` | 1744 | ширина колонки контента (`1920 − 88 × 2`) |
| `FOOTER_H` | 60 | зона колонтитула снизу |

Контент никогда не заходит в поля. Исключение — фоновые заливки и изображения
«в край» (титул, разделитель, панель в `split`): они идут от 0 до 1920.

`contentBottom()` возвращает нижнюю границу контентной зоны: `1080 − 72 − 60 = 948`
на слайдах с колонтитулом и `1008` без него.

## Шапка слайда

Все контентные макеты начинаются с `header()`. Он рисует надзаголовок, заголовок и
лид и возвращает `Y`, с которого идёт контент:

```js
const y0 = TN.header(s, { title: 'Цена разрозненности', lead: 'Замеры на трёх заводах, апрель 2026.' });
```

Заголовок сам уменьшается с 68 px до 40 px, если длинный. Лид — максимум 1360 px
в ширину, чтобы строка не была слишком длинной для чтения.

Порядок и отступы внутри шапки:

```
MT (72)
  надзаголовок 28 px капсом, цвет акцента     → +46
  заголовок 68 px bold, интерлиньяж 1.08      → +высота +20 (или +40, если лида нет)
  лид 32 px, цвет n60, интерлиньяж 1.4        → +высота +44
y0 — отсюда начинается контент
```

## Колонтитул

Ставится на все контентные слайды. Не ставится на `title`, `section`, `statement`
и `closing` — там он мешает.

```js
TN.footer(s, p, { label: 'TN Life · Стратегия продукта 2026', no: 4, total: 14 });
```

Слева — подпись (22 px, `n50`), справа — номер страницы: текущий полужирным `n100`,
« / всего» светлым `n40`. Нумеруются только слайды с колонтитулом, сквозной счёт
по ним, а не по всем слайдам деки.

## Как ставить блоки

- **Шаг сетки — 4 px.** Ходовые отступы: 16, 20, 24, 28, 32, 40, 48, 64, 72, 88.
- **Промежуток между карточками** — 32 px в сетке, 40 px между крупными метриками.
- **Внутренние поля карточки** — 40 px (сетка карточек) или 48 px (метрики).
- Радиусы: 20 px — плитка под иконку, 28 px — карточка, 32 px — крупная карточка
  и рамка изображения, 50 % — круг.

## Высота блоков считается, а не угадывается

Прежде чем ставить блок, посчитай его высоту — иначе текст налезет на следующий:

```js
const h = TN.blockH(text, ширина, кегль, bold, интерлиньяж);   // → высота в px
const f = TN.fit(text, { w, h: доступно, size: 68, min: 40, bold: true, lh: 1.08 });
```

`fit()` возвращает `{ size, lines }` — кегль, при котором текст умещается.
Для заголовков и крупных цифр используй его всегда: русские строки длиннее английских
на 10–15 %, и то, что улеглось в макете, вылезает на живом тексте.

Если карточки в ряду содержат текст разной длины — посчитай высоту по самой длинной
и примени ко всем, иначе подписи в ряду разъедутся по вертикали.

## Текстовые блоки

У текстовых боксов PowerPoint есть собственные внутренние поля. Пролог ставит
`margin: 0` — благодаря этому координата текста совпадает с координатой фигуры.
Если пишешь `addText` мимо `txt()`, не забудь `margin: 0` и `isTextBox: true`.

## Интерлиньяж

| Что | Интерлиньяж |
|---|---|
| титул, разделитель | 1.04–1.05 |
| заголовок слайда | 1.08 |
| заголовок карточки | 1.15 |
| лид, основной текст | 1.35–1.45 |
| цитата | 1.25 |
