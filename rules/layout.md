# Сетка и координаты

## Холст

Слайд — **1920 × 1080 px**, соотношение 16:9. В PowerPoint это 13,333 × 7,5 дюйма.
Все шаблоны написаны в пикселях макета; пролог переводит их сам:

```js
const px = (n) => n / 144;   // px → дюймы: 144 px = 1 дюйм
const pt = (n) => n / 2;     // px → пункты кегля: 2 px = 1 pt
```

Значит, 64 px заголовка на слайде — это 32 pt в PowerPoint. Думай и пиши в пикселях,
конвертацию не делай руками.

## Поля

| Величина | px | Что это |
|---|---|---|
| `MX` | 96 | левое и правое поле |
| `MT` | 80 | верхнее поле |
| `MB` | 80 | нижнее поле |
| `CW` | 1728 | ширина колонки контента (`1920 − 96 × 2`) |
| `FOOTER_H` | 64 | зона колонтитула снизу |

Контент никогда не заходит в поля. Исключение — фоновые заливки и изображения
«в край» (титул, разделитель, панель в `split`): они идут от 0 до 1920.

`contentBottom()` возвращает нижнюю границу контентной зоны: `1080 − 80 − 64 = 936`
на слайдах с колонтитулом и `1000` без него.

## Шапка слайда

Все контентные макеты начинаются с `header()`. Он рисует надзаголовок, заголовок и
лид и возвращает `Y`, с которого идёт контент:

```js
const y0 = TN.header(s, { title: 'Цена разрозненности', lead: 'Замеры на трёх заводах, апрель 2026.' });
```

Заголовок сам уменьшается с 64 px до 40 px, если длинный. Лид — максимум 1280 px
в ширину, чтобы строка не была слишком длинной для чтения.

Порядок и отступы внутри шапки:

```
MT (80)
  надзаголовок 22 px капсом, трекинг +2,4, цвет акцента → +42
  заголовок 64 px bold, интерлиньяж 1.06                → +высота +18 (или +48, если лида нет)
  лид 30 px, цвет muted, интерлиньяж 1.4                → +высота +56
y0 — отсюда начинается контент
```

## Колонтитул

Ставится на все контентные слайды. Не ставится на `title`, `section`, `statement`
и `closing` — там он мешает.

```js
TN.footer(s, p, { label: 'TN Life · Стратегия продукта 2026', no: 4, total: 14 });
```

Слева — подпись (20 px, `soft`), справа — номер страницы: текущий полужирным `muted`,
« / всего» светлым `faint`. Нумеруются только слайды с колонтитулом, сквозной счёт
по ним, а не по всем слайдам деки.

## Как ставить блоки

- **Шаг сетки — 4 px.** Ходовые отступы: 12, 16, 24, 32, 48, 64 (`TN.GAP`).
- **Промежуток между карточками** — 32 px; между шагами процесса — 28 px.
- **Внутренние поля карточки** — 36 px (сетка карточек, шаги) или 44 px (метрики).
- Радиусы — три (`TN.R`): `tile` 18 px — плитка под иконку, `card` 24 px — карточка,
  `big` 28 px — крупная карточка и рамка изображения. Плюс круг и пилюля.

## Вертикальная композиция

Главное правило системы: **блок имеет высоту своего содержимого, а не высоту зоны.**
Карточка, растянутая до колонтитула ради «заполненности», выглядит хуже, чем
компактный ряд карточек и воздух вокруг него.

Свободное место распределяется в таком порядке:

1. в зазоры между строками и карточками — до разумного предела;
2. остаток — в оптический центр: сверху чуть меньше, чем снизу.

Три примитива пролога:

```js
// блок высотой need в зоне [top, bottom]; bias — доля слака сверху
const y = TN.place(y0, TN.contentBottom(), need, 0.4);

// ряд из n строк высотой rowH: шаг растёт за счёт свободного места
const { top, step, gap } = TN.rows(y0, TN.contentBottom(), n, rowH, { min: 28, max: 96 });

// высота карточки: по контенту, с небольшим запасом, но не на всю зону
const ch = TN.boxH(need, TN.contentBottom() - y0, { grow: 1.15 });
```

`bias` ≈ 0,4 — оптический центр: при равных полях блок кажется сползающим вниз,
поэтому сверху оставляем меньше. Для блоков, которые логически «висят» на шапке
(списки, таблица, дорожная карта), bias 0,2–0,3.

## Высота блоков считается, а не угадывается

Прежде чем ставить блок, посчитай его высоту — иначе текст налезет на следующий:

```js
const h = TN.blockH(text, ширина, кегль, bold, интерлиньяж);   // → высота в px
const f = TN.fit(text, { w, h: доступно, size: 64, min: 40, bold: true, lh: 1.06 });
```

`fit()` возвращает `{ size, lines }` — кегль, при котором текст умещается.
Для заголовков и крупных цифр используй его всегда: русские строки длиннее английских
на 10–15 %, и то, что улеглось в макете, вылезает на живом тексте.

Если карточки в ряду содержат текст разной длины — посчитай высоту по самой длинной
и примени ко всем, иначе подписи в ряду разъедутся по вертикали.

Оценка ширины строки приблизительная. Там, где ошибка на одну строку означала бы
наложение (подпись под тезисом, сноска под таблицей), подпирай блок снизу: ставь его
не «после текста», а `Math.min(после текста, граница поля)`.

## Текстовые блоки

У текстовых боксов PowerPoint есть собственные внутренние поля. Пролог ставит
`margin: 0` — благодаря этому координата текста совпадает с координатой фигуры.
Если пишешь `addText` мимо `txt()`, не забудь `margin: 0` и `isTextBox: true`.

## Интерлиньяж

| Что | Интерлиньяж |
|---|---|
| титул, разделитель | 1.05 |
| заголовок слайда | 1.06 |
| заголовок карточки | 1.2 |
| лид, основной текст | 1.35–1.45 |
| цитата, тезис | 1.15–1.28 |
