# Чек-лист приёмки

Проходить перед тем, как отдать деку. Не по памяти — по отрендеренным картинкам.

## Как смотреть

```bash
node build.js
soffice --headless --convert-to pdf out.pptx
pdftoppm -jpeg -r 110 out.pdf slide
```

Открой **каждый** `slide-*.jpg`. После написания кода глаз видит то, что задумано,
а не то, что отрисовалось, — поэтому смотреть надо картинки, а не код.

Если в системе не установлен Inter, рендер подставит другой шрифт и ширина строк
будет неточной: где-то покажет перенос, которого в PowerPoint не будет, и наоборот.
Сам `.pptx` при этом ссылается на Inter. Это влияет только на превью.

## Вёрстка

- [ ] Текст нигде не вылезает за рамку блока и за край слайда.
- [ ] Нет наложений: текст не идёт поверх фигуры, подпись не налезает на колонтитул.
- [ ] Отступы от краёв соблюдены: 96 px по бокам, 80 px сверху и снизу.
- [ ] Карточки в ряду одной высоты, подписи в них выровнены по одной линии.
- [ ] Колонки и одинаковые элементы выровнены между собой.
- [ ] Нет слайда, где контент занял четверть площади, а остальное пусто.
- [ ] Нет карточки, растянутой на всю зону, у которой текст кончается на трети высоты.
- [ ] Промежутки одинаковые: не 24 px в одном месте и 37 px в соседнем.

## Контент

- [ ] Ни одного забытого плейсхолдера «Изображение · вставьте 1000×650» там, где
      картинка была обещана.
- [ ] Нет заглушек `Lorem`, `TODO`, `XXX`, «текст слайда».
- [ ] Нумерация страниц сквозная и совпадает с общим числом контентных слайдов.
- [ ] Заголовки — утверждения, а не рубрики (`rules/voice.md`).
- [ ] У каждой цифры есть источник и период.
- [ ] Цифры сходятся с исходниками пользователя. Ничего не придумано.

## Бренд

- [ ] Цвета только из `rules/brand.md`. Ни одного цвета «на глаз».
- [ ] Шрифт один на всю деку.
- [ ] Логотип есть на титуле и финале, на контентных слайдах его нет.
- [ ] На красном и тёмном фоне логотип белый, не чёрный.
- [ ] Иконки из спрайта ТН, эмодзи нет.
- [ ] Зелёный — рост и улучшение, красный — падение и проблема.
- [ ] Текст читается: нет светло-серого по светлому и тёмного по тёмному.

## Структура

- [ ] Ни один макет не повторяется два слайда подряд.
- [ ] Перед каждым крупным блоком есть разделитель.
- [ ] Ни на одном слайде не больше одного тезиса.
- [ ] Список не длиннее 8 пунктов, карточек не больше 8, метрик не больше 4,
      шагов не больше 6, строк в таблице и дорожной карте не больше 8.
- [ ] На схемах: узлов не больше 10, участников в `sequence` не больше 6,
      контейнеров в `architecture` не больше 6, точек в `matrix` не больше 10.
- [ ] Стрелки на схеме идут в одну сторону и не пересекают блоки.
- [ ] Финальный слайд говорит, к кому идти дальше.

## Файл

- [ ] `.pptx` открывается и не просит восстановления.
- [ ] Текст, таблицы и диаграммы редактируются — это не картинки.
- [ ] Заметки докладчика на месте, если их просили.

Если есть скилл `pptx`, прогоняй ещё и его валидатор:

```bash
python3 <путь к скиллу pptx>/scripts/office/validate.py out.pptx
```

## Частые ошибки

| Симптом | Причина |
|---|---|
| Текст обрезан снизу | высота блока не посчитана, взята «на глаз» |
| Пустая нижняя треть карточки | высота задана по зоне, а не по контенту: считай `TN.boxH()` |
| Подписи в карточках на разной высоте | высота блока считалась по каждой карточке, а не по самой длинной в ряду |
| Текст съехал относительно фигуры | у текстового бокса не выставлен `margin: 0` |
| Столбцы одной серии разного цвета | не задан один цвет: `varyColors` работает только для круговых |
| Первая категория горизонтальных баров внизу | PowerPoint рисует их снизу вверх — разверни порядок категорий и значений |
| Логотип чёрным пятном на красном | взята непрозрачная JPG-версия вместо перекраски PNG в белый |
| Заголовок налез на второй абзац | не учтён перенос: русская строка длиннее английской на 10–15 % |
